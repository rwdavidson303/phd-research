# Qualitative Analysis Software Guide and Pre-Program Learning Plan

---

## 1. Purpose

This guide helps you prepare for qualitative data analysis before beginning the Indiana University Kelley DBA program in Fall 2026. It compares the two leading qualitative data analysis software (QDAS) platforms, recommends a tool based on your research design, provides a 3-month learning plan, and maps the software setup to the coding architecture in your case study research design.

Investing time in learning QDAS before the program starts gives you a meaningful head start. Most incoming DBA students spend their first year learning both theory and tools simultaneously. With your quantitative pilot study complete and your case study design drafted, you can dedicate pre-program time to building the technical proficiency that will make ARP I-IV and dissertation analysis substantially more efficient.

## 2. Software Comparison: NVivo 15 vs. ATLAS.ti 24

### 2.1 Feature Comparison

| Feature | NVivo 15 | ATLAS.ti 24 |
|---------|----------|-------------|
| **Platform** | Windows (full), Mac (reduced features) | Windows and Mac (full feature parity) |
| **Current Version** | NVivo 15 (Lumivero) | ATLAS.ti 24 |
| **Pricing (Individual)** | ~$99/year student; ~$1,399 perpetual | ~$99/year student; ~$1,190 perpetual (desktop) |
| **Cloud Option** | NVivo Collaboration Cloud | ATLAS.ti Web (included with desktop license) |
| **Mac Compatibility** | Functional but historically feature-lagged vs. Windows | Full parity -- identical interface on Mac and Windows |
| **Learning Curve** | Steeper; more powerful query system requires upfront investment | Gentler; intuitive drag-and-drop interface |
| **Coding** | Hierarchical node structure; auto-coding | Code-and-code group structure; AI-assisted coding |
| **Memo System** | Strong; linked to codes and sources | Strong; standalone and linked memos |
| **Visualization** | Explore diagrams, comparison diagrams, hierarchy charts | Network views (distinctive strength), Sankey diagrams, code co-occurrence |
| **Cross-Case Analysis** | Case classification sheets; matrix coding queries | Code-document tables; co-occurrence tables; quotation manager |
| **Team Collaboration** | NVivo Collaboration Cloud (paid add-on) | ATLAS.ti Web (browser-based, real-time) |
| **Import Formats** | PDFs, Word, audio, video, images, surveys, social media, datasets | PDFs, Word, audio, video, images, surveys, geo data |
| **Query System** | Powerful Boolean queries, matrix queries, framework matrices | Code co-occurrence, code-document table, query tool |
| **AI Features** | AI-assisted coding (NVivo 15) | AI Coding, AI Summaries, AI Search (ATLAS.ti 24) |
| **Data Security** | Local storage; optional cloud | Local storage; optional web |
| **Export** | Excel, SPSS, Word, PDF | Excel, Word, PDF, SPSS, GraphML |
| **Community/Support** | Large user community; Lumivero Academy | ATLAS.ti Academy; strong YouTube channel |
| **Institutional Prevalence** | More common in US universities | Growing rapidly; more common in Europe |

### 2.2 Head-to-Head Assessment for Your Project

**Your requirements:** Mac-native environment, multi-case study design (5 cases), 25-35 interviews, document analysis, cross-case comparison, theory-driven coding architecture with 6 code groups, sole researcher (no team collaboration needed).

| Criterion | NVivo 15 | ATLAS.ti 24 | Edge |
|-----------|----------|-------------|------|
| Mac experience | Functional but historically weaker | Full feature parity | **ATLAS.ti** |
| Multi-case organization | Case classification system | Document groups + code-document tables | Tie |
| Network/relationship visualization | Basic explore diagrams | Powerful network views | **ATLAS.ti** |
| Code group management | Hierarchical node trees | Flat code groups with nesting | Tie |
| Cross-case queries | Matrix coding queries (powerful) | Code co-occurrence + quotation manager | **NVivo** (slight) |
| Learning resources | More textbooks reference NVivo | Growing ATLAS.ti Academy resources | **NVivo** (slight) |
| AI-assisted features | New in v15 | More mature AI tools in v24 | **ATLAS.ti** |
| Price (student) | ~$99/year | ~$99/year | Tie |
| Speed to productivity | Longer learning curve | Faster to basic competency | **ATLAS.ti** |

### 2.3 Recommendation

**Primary recommendation: ATLAS.ti 24**

For a Mac-based sole researcher conducting a multi-case study with a pre-defined coding architecture, ATLAS.ti 24 offers the best fit:

1. **Full Mac parity** eliminates the risk of hitting feature gaps that have historically plagued NVivo's Mac version
2. **Network views** are a distinctive strength for visualizing relationships between codes, quotations, and memos -- directly useful for mapping the theoretical constructs (TCE, public value theory) to empirical patterns
3. **Gentler learning curve** means faster time-to-productivity, important when learning pre-program on your own
4. **AI-assisted coding** in ATLAS.ti 24 is more mature and can accelerate initial coding passes (while you still manually review and refine)
5. **Document groups** map naturally to your multi-case design (one group per case)

**Critical caveat: Check with IU first.** Before purchasing, contact the Kelley DBA program office to ask:
- Does the university provide an institutional license for NVivo or ATLAS.ti?
- Do qualitative methods courses in the program use one platform specifically?
- Does your anticipated methods advisor have a preference?

If IU provides a free NVivo license and teaches with NVivo, use NVivo -- the institutional support and classroom alignment outweigh ATLAS.ti's technical advantages. A free tool with professor support beats a paid tool you learn alone.

## 3. Three-Month Pre-Program Learning Plan (April--June 2026)

### 3.1 Month 1: Foundations (April 2026)

**Goal:** Install software, learn the interface, complete first practice project.

**Week 1: Setup and Orientation**
- Download and install ATLAS.ti 24 (or NVivo if IU provides it)
- Complete the platform's built-in tutorial/sample project
- Watch the "Getting Started" video series (ATLAS.ti Academy or NVivo tutorials)
- Familiarize yourself with the interface: document manager, code manager, quotation manager, memo manager

**Week 2: Coding Fundamentals**
- Learn to create codes, code groups, and apply codes to text segments
- Practice open coding on a sample document (use one of your literature review articles)
- Learn to create and link memos
- Understand the difference between in-vivo codes, descriptive codes, and process codes (Saldana, 2021)

**Week 3: Practice Project -- Single Document**
- Import a published qualitative procurement study (e.g., a case study from Journal of Public Procurement)
- Code the article's findings section using your draft coding architecture (the 6 code groups from your research design)
- Write 3-5 memos reflecting on the coding process
- Export a code frequency report

**Week 4: Practice Project -- Multi-Document**
- Import 3-4 additional articles from your literature review
- Code them using the same coding architecture
- Practice merging, splitting, and renaming codes
- Generate a code co-occurrence table
- Create your first network view (ATLAS.ti) or explore diagram (NVivo)

### 3.2 Month 2: Intermediate Skills (May 2026)

**Goal:** Learn cross-case organization, practice with interview-style data, build queries.

**Week 5: Case Organization**
- Set up document groups representing your 5 planned cases (even with placeholder data)
- Learn to use document-level attributes/variables (agency type, complexity level, method used, outcome)
- Practice filtering by document group

**Week 6: Interview Transcript Practice**
- Find or create a mock interview transcript (~3,000 words)
- Practice coding the transcript using all three coding cycles: initial/open, focused, and theoretical
- Write analytic memos after each coding cycle
- Practice the constant comparison method: how does this passage relate to previously coded segments?

**Week 7: Cross-Case Analysis Tools**
- Generate a code-document table (which codes appear in which cases)
- Build a cross-case matrix comparing themes across cases
- Practice writing cross-case memos that synthesize patterns
- Learn to use the quotation manager to retrieve all quotations for a specific code across all cases

**Week 8: Visualization and Reporting**
- Create network views showing relationships between code groups and theoretical constructs
- Build a visualization of your coding architecture (code groups linked to research questions)
- Practice exporting results to Word/Excel for inclusion in research reports
- Generate a codebook export (code definitions, example quotations, frequency counts)

### 3.3 Month 3: Advanced Skills and Project Setup (June 2026)

**Goal:** Set up the actual dissertation project, practice reliability techniques, build comfort with the full workflow.

**Week 9: Dissertation Project Setup**
- Create your actual dissertation QDAS project file
- Import the coding architecture from your research design (all 6 code groups, individual codes, and code definitions)
- Set up document groups for each planned case
- Create memo folders for: methodological memos, analytic memos, theoretical memos, reflexivity journal
- Import your quantitative pilot study summary as a background document

**Week 10: Trustworthiness Tools**
- Practice inter-coder reliability: code a document, then re-code it a week later and compare
- Learn to use the software's inter-coder agreement features (if available)
- Practice creating an audit trail using memos and project journaling
- Set up a reflexivity journal template

**Week 11: Advanced Queries**
- Learn Boolean and proximity queries (e.g., "find all passages coded as both 'complexity assessment' AND 'LPTA preference'")
- Practice GREP/text search within coded segments
- Build query templates for the cross-case comparisons you anticipate needing
- Learn to save and re-run queries

**Week 12: Full Workflow Rehearsal**
- Import 2-3 documents as a mini-pilot case
- Run through the complete workflow: import, initial coding, focused coding, memo writing, network view, cross-case query, codebook export
- Identify gaps in your skills and target them for continued learning during ARP I
- Back up your project file and establish a backup routine

├── Case 4: Department of Veterans Affairs (VA)

### 4.2 Code Groups Mapped to Software

The six code groups from the research design translate directly to the QDAS code group structure:

| # | Code Group | # of Codes | Software Setup |
|---|-----------|------------|----------------|
| 1 | Decision Factors | 9 | Code Group: "1-Decision Factors" with 9 child codes |
| 2 | Post-Award Dynamics | 8 | Code Group: "2-Post-Award" with 8 child codes |
| 3 | Theoretical Constructs | 8 | Code Group: "3-Theory" with 8 child codes |
| 4 | Organizational Factors | 6 | Code Group: "4-Org Factors" with 6 child codes |
| 5 | Contextual Factors | 6 | Code Group: "5-Context" with 6 child codes |
| 6 | Market/Competition | 6 | Code Group: "6-Market" with 6 child codes |
| -- | *Emergent codes* | TBD | Code Group: "7-Emergent" for codes that arise inductively |

**Naming convention:** Prefix codes with their group number for easy sorting and identification.
- Example: `1.01 Regulatory guidance`, `1.02 Agency culture/norms`, `1.03 Protest risk perception`
- Example: `3.01 TCE: Asset specificity`, `3.02 TCE: Uncertainty`

### 4.3 Key Queries to Build

These queries support the cross-case analysis described in the research design:

1. **Code-Document Table:** For each code group, generate a matrix of code frequency by case -- the foundation of cross-case comparison
2. **Code Co-Occurrence:** Which codes frequently appear together? (e.g., Do "complexity assessment" and "tradeoff preference" co-occur?)
3. **Quotation Retrieval by RQ:** Retrieve all quotations linked to codes mapped to each research question
4. **Within-Case Summaries:** For each case, list all codes applied with frequency and example quotations
5. **Cross-Case Pattern Matching:** Compare the code profiles of LPTA-heavy agencies vs. tradeoff-heavy agencies
6. **Theoretical Construct Saturation:** For each theoretical construct (TCE, public value, etc.), how many cases and how many quotations support it?

## 5. Recommended Learning Resources

### 5.1 Essential Books

| Book | Author(s) | Year | Focus |
|------|-----------|------|-------|
| *The Coding Manual for Qualitative Researchers* (4th ed.) | Johnny Saldana | 2021 | The definitive guide to coding methods. Covers 30+ coding approaches organized by first cycle, second cycle, and post-coding methods. Essential reference. |
| *Qualitative Data Analysis: A Methods Sourcebook* (4th ed.) | Miles, Huberman, & Saldana | 2020 | Practical, systematic approach to qualitative analysis. Excellent on displays (matrices, networks) and cross-case analysis. |
| *Using Software in Qualitative Research: A Step-by-Step Guide* (3rd ed.) | Silver & Lewins | 2014 | Software-neutral guide to using QDAS effectively. Covers NVivo and ATLAS.ti. Older edition but conceptual guidance still valuable. |
| *Case Study Research and Applications* (6th ed.) | Robert K. Yin | 2018 | The methodological foundation for your study. Chapter 5 on analysis is directly relevant to software setup. |

### 5.2 Online Tutorials and Courses

**ATLAS.ti Resources:**
- ATLAS.ti Academy (academy.atlasti.com) -- free structured learning path with video tutorials
- ATLAS.ti YouTube channel -- 200+ tutorial videos covering all features
- "Qualitative Data Analysis with ATLAS.ti" (SAGE/Coursera) -- structured course

**NVivo Resources:**
- Lumivero Learning Center -- free tutorials and webinars
- NVivo YouTube channel -- feature-specific tutorials
- "Qualitative Data Analysis with NVivo" by Pat Bazeley & Kristi Jackson (2019) -- the standard NVivo textbook

**General Qualitative Methods:**
- SAGE Research Methods Online -- video tutorials on coding, case study analysis, and QDAS
- Coursera: "Qualitative Research Methods" (University of Amsterdam) -- free audit
- YouTube: "Qualitative Coding and Analysis" by Delve (clear, practical coding tutorials)

### 5.3 Journal Articles on QDAS Use

- Woods, M., Paulus, T., Atkins, D. P., & Macklin, R. (2016). Advancing qualitative research using qualitative data analysis software (QDAS)? Reviewing potential versus practice in published studies using ATLAS.ti and NVivo, 1994-2013. *Social Science Computer Review*, *34*(5), 597-617.
- Friese, S. (2019). *Qualitative data analysis with ATLAS.ti* (3rd ed.). SAGE. [The definitive ATLAS.ti textbook.]
- Jackson, K., & Bazeley, P. (2019). *Qualitative data analysis with NVivo* (3rd ed.). SAGE. [The definitive NVivo textbook.]
