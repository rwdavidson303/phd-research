# PhD Research: From Lowest Price to Highest Public Value

An Empirical Test of Best-Value Source Selection in Government RFPs

**Richard Davidson**
Indiana University, Kelley School of Business, DBA Program

## Key Data Sources

- **USAspending.gov** - Federal contract award data
- **FPDS** - Federal Procurement Data System (source selection process codes)
- **GAO** - Bid protest statistics and reports
- **CPARS** - Contractor Performance Assessment Reporting System
- **Google Scholar** - Academic literature

## Research Questions

1. Best-value tradeoff vs. LPTA outcomes
2. Bid-protest/appeal system effects on procurement
3. Solicitation quality and requirements clarity
4. Post-award oversight effects
5. Lowest price and post-award renegotiation
6. Incumbency advantage in RFP design
7. Reform recommendations for value-based procurement
